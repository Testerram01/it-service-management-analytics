
# IT Service Management Analytics & Process Improvement

## 1. Project Overview
- This independent portfolio project analyzes fictional IT support incidents to understand incident trends, resolution performance, and SLA compliance.

## 2. Business Problem
- IT support teams need to understand which incident categories occur most often, how efficiently tickets are resolved, and whether service-level targets are being met.

## 3. Project Objectives
- Analyze incident volume and trends.
- Measure SLA compliance.
- Compare incident resolution performance by priority and category.
- Explore the relationship between simulated deployments and incidents.
- Recommend process improvements based on the analysis.

## 4. Tools Used
- Microsoft Excel
- SQL
- Microsoft Power BI
- GitHub

## 5. Dataset
All data used in this project is fictional and created for learning purposes. No company, client, or confidential information is included.

## 6. Methodology
1. Define the business requirements and KPIs.
2. Clean and validate the dataset.
3. Analyze the data using Excel and SQL.
4. Build an interactive Power BI dashboard.
5. Document requirements, testing, and recommendations.
